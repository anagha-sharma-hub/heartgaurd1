# HeartGuard
HeartGuard is a machine learning web app that estimates a person's 10-year risk of cardiovascular disease. The user enters 13 health details (such as age, blood pressure and lifestyle habits), and a Random Forest model with 150 decision trees returns a risk percentage, a colour-coded risk level and the key factors affecting the score. Past checkups are saved locally so users can track changes over time.

- Model: Random Forest, trained on 3,000 records, about 84% accuracy
- Deployed on: Vercel
- Live demo: https://heartgaurd1-w4cz.vercel.app/

For educational purposes only. Not a substitute for medical advice.
